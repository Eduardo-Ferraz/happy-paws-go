# Documentação — Happy Paws

Este repositório guarda o **protótipo navegável** do Happy Paws (aplicação React/Vite,
em `src/`) e a **documentação das duas disciplinas** em que o sistema foi trabalhado.
As duas fases são independentes e estão separadas abaixo.

| Pasta | Disciplina | O que tem |
|---|---|---|
| [`es1-requisitos/`](es1-requisitos/) | **Engenharia de Software I** (2025/2, Profa. Monalessa Perini Barcellos) | Especificação e análise de requisitos: propósito, minimundo, user stories com critérios de aceitação, requisitos não funcionais e modelagem conceitual. |
| [`es2-projeto/`](es2-projeto/) | **Engenharia de Software II** (2026/2, Prof. Vítor E. Silva Souza) | Projeto (*design*) do sistema: plataforma, atributos de qualidade, arquitetura, lógica de negócio, interação humano-computador e protótipo de alta fidelidade. |

## Como as duas fases se ligam

ES1 respondeu **o que** o sistema faz (requisitos) e materializou isso no protótipo
navegável deste repositório, publicado em <https://happypawss.lovable.app>.

ES2 parte desses requisitos e responde **como** o sistema é construído: subsistemas,
camadas, componentes de domínio do problema (CDP), de gerência de tarefas (CGT), de
interface com o usuário (CIU) e de gerência de dados (CGD). O código deste repositório
**não** é a implementação do projeto de ES2 — é o protótipo de ES1. A plataforma
escolhida no projeto (Next.js, PostgreSQL, Drizzle ORM) está descrita no Capítulo 2 do
documento de projeto.
